这是我学习 React Native 的第一篇笔记，后面会按分类慢慢补充学习记录。

## 环境准备

在开始之前，需要先准备开发环境：

- Node.js
- JDK
- Android Studio（安卓开发）或 Xcode（iOS 开发）
- 也可以先用 Expo 快速上手

## 创建第一个项目

```bash
npx @react-native-community/cli init MyApp
```
